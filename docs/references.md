# Papers

The models implemented in pyBBTD are described in:

- **Cov-LL1**: [paper on IEEE Xplore](https://ieeexplore.ieee.org/abstract/document/10446019).
- **BBTD**: [paper on HAL](https://hal.science/hal-05059862/).
- **LL1 / block term decompositions**, on which Cov-LL1 builds:
  [paper on SIAM](https://epubs.siam.org/doi/abs/10.1137/070690729).

Cov-LL1 and BBTD are covered in detail in chapters 3 and 4 of this
[PhD thesis](https://theses.fr/s348607).
