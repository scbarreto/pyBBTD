Uniqueness

Uniqueness#

See Ranks and uniqueness for how these checks are used.

.. py:module:: pybbtd.uniqueness

Sufficient conditions for the BTD and BBTD models to have a unique solution.

A decomposition is essentially unique when the terms it finds are the only ones that explain the data, up to the order of the terms and scalings inside each term. When uniqueness holds, the recovered terms can be interpreted as the true underlying sources.

.. py:function:: check_uniqueness_bbtd(N1, N2, N3, N4, R, L1, L2) :module: pybbtd.uniqueness

Check a sufficient uniqueness condition for a rank-(L1, L1, L2, L2) BBTD.

The fourth-order model is reshaped into two third-order BTD models, and the BBTD is unique if either of them is:

  • merging modes 1 and 2 gives a BTD of size (N3, N4, N1 * N2) with block rank L2;

  • merging modes 3 and 4 gives a BTD of size (N1, N2, N3 * N4) with block rank L1.

:param N1: Dimensions of the fourth-order tensor. :type N1: int :param N2: Dimensions of the fourth-order tensor. :type N2: int :param N3: Dimensions of the fourth-order tensor. :type N3: int :param N4: Dimensions of the fourth-order tensor. :type N4: int :param R: Number of terms. :type R: int :param L1: Rank of the first block (modes 1 and 2). :type L1: int :param L2: Rank of the second block (modes 3 and 4). :type L2: int

:returns: True if a sufficient condition for uniqueness is satisfied. :rtype: bool

.. py:function:: check_uniqueness_ll1(N1, N2, N3, R, L) :module: pybbtd.uniqueness

Check a sufficient uniqueness condition for a rank-(L, L, 1) BTD.

Five sufficient conditions from the BTD uniqueness theory are evaluated; if any of them holds, the decomposition is essentially unique.

:param N1: Dimensions of the third-order tensor (the rank-one mode is the third). :type N1: int :param N2: Dimensions of the third-order tensor (the rank-one mode is the third). :type N2: int :param N3: Dimensions of the third-order tensor (the rank-one mode is the third). :type N3: int :param R: Number of terms. :type R: int :param L: Rank of the matrix part of each term. :type L: int

:returns: True if a sufficient condition for uniqueness is satisfied. :rtype: bool
