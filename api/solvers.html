BTD: ALS#

.. py:module:: pybbtd.solvers.btd_als

Alternating least squares (ALS) solver for the BTD model.

.. py:function:: fit_btd_als(model, T, init=’random’, max_iter=1000, abs_tol=1e-08, rel_tol=0.001) :module: pybbtd.solvers.btd_als

Fit a BTD with alternating least squares (ALS).

Each iteration solves a least-squares problem for A, then B, then C, keeping the other factors fixed. All three block modes are supported.

:param model: Model defining the dimensions, ranks and block mode. :type model: BTD :param T: Tensor of shape model.dims to decompose. :type T: np.ndarray :param init: Initialization strategy (see :func:init_btd_factors). :type init: {“random”, “svd”}, default “random” :param max_iter: Maximum number of iterations. :type max_iter: int, default 1000 :param abs_tol: Stop when fit_error / ||T|| falls below this value. :type abs_tol: float, default 1e-8 :param rel_tol: Stop when the relative decrease of the fit error falls below this value. :type rel_tol: float, default 1e-3

:returns: * factors (list of np.ndarray) – Estimated [A, B, C]. * fit_error (np.ndarray) – Squared reconstruction error :math:\|\mathcal{T} - \hat{\mathcal{T}}\|^2 at initialization and after each iteration.

.. py:function:: init_btd_factors(model, strategy=’random’, T=None) :module: pybbtd.solvers.btd_als

Initialize the BTD factors.

The factors are returned in the LL1 layout: A and B have sum(L) columns and C has R columns.

:param model: Model defining the dimensions and ranks. :type model: BTD :param strategy: "random" draws standard Gaussian entries. "svd" uses the leading singular vectors of each unfolding of T. :type strategy: {“random”, “svd”}, default “random” :param T: Data tensor, required for "svd". :type T: np.ndarray, optional

:returns: A, B, C – Initial factor matrices. :rtype: np.ndarray

Cov-LL1: AO-ADMM#

.. py:module:: pybbtd.solvers.covll1_admm

AO-ADMM solver for the Cov-LL1 model.

.. py:function:: fit_covll1_admm(model, T, init=’random’, max_iter=1000, rho=1, max_admm=1, rel_tol=1e-10, abs_tol=1e-10, admm_tol=1e-08) :module: pybbtd.solvers.covll1_admm

Fit a Cov-LL1 model with AO-ADMM.

The factors are updated in turn (A, then B, then C), each with a few ADMM iterations. A and B are kept real and non-negative, and each column of C is kept a vectorized covariance matrix (Hermitian positive semidefinite).

:param model: Model defining the dimensions and ranks. :type model: CovLL1 :param T: Tensor of shape (I, J, K**2) to decompose. :type T: np.ndarray :param init: Initialization strategy (see :func:init_covll1_factors). :type init: {“random”, “kmeans”}, default “random” :param max_iter: Maximum number of outer iterations. :type max_iter: int, default 1000 :param rho: Initial ADMM penalty parameter. :type rho: float, default 1 :param max_admm: Maximum number of inner ADMM iterations per factor update. :type max_admm: int, default 1 :param rel_tol: Stop when the relative decrease of the fit error falls below this value. :type rel_tol: float, default 1e-10 :param abs_tol: Stop when fit_error / ||T|| falls below this value. :type abs_tol: float, default 1e-10 :param admm_tol: Tolerance of the inner ADMM loops. :type admm_tol: float, default 1e-8

:returns: * factors (list of np.ndarray) – Estimated [A, B, C]. * fit_error (np.ndarray) – Normalized squared reconstruction error :math:\|\mathcal{T} - \hat{\mathcal{T}}\|^2 / \|\mathcal{T}\|^2 at initialization and after each iteration.

.. py:function:: init_covll1_factors(model, strategy=’random’, T=None) :module: pybbtd.solvers.covll1_admm

Initialize the Cov-LL1 factors.

:param model: Model defining the dimensions and ranks. :type model: CovLL1 :param strategy: "random" draws factors with :func:~pybbtd.covll1.generate_covll1_factors. "kmeans" clusters the pixels by their covariance matrices (see :func:_kmeans_init). :type strategy: {“random”, “kmeans”}, default “random” :param T: Data tensor, required for "kmeans". :type T: np.ndarray, optional

:returns: A, B, C – Initial factor matrices; A and B are non-negative. :rtype: np.ndarray

Stokes: AO-ADMM#

.. py:module:: pybbtd.solvers.stokes_admm

AO-ADMM solver for the Stokes model.

.. py:function:: fit_stokes_admm(model, T, init=’random’, max_iter=1000, rho=1, max_admm=1, rel_tol=1e-10, abs_tol=1e-10, admm_tol=1e-08) :module: pybbtd.solvers.stokes_admm

Fit a Stokes model with AO-ADMM.

The factors are updated in turn (A, then B, then C), each with a few ADMM iterations. A and B are kept non-negative and every column of C is kept a valid Stokes vector.

:param model: Model defining the dimensions and ranks. :type model: Stokes :param T: Tensor of shape (I, J, 4) to decompose. :type T: np.ndarray :param init: Initialization strategy (see :func:init_stokes_factors). :type init: {“random”, “kmeans”}, default “random” :param max_iter: Maximum number of outer iterations. :type max_iter: int, default 1000 :param rho: Initial ADMM penalty parameter. :type rho: float, default 1 :param max_admm: Maximum number of inner ADMM iterations per factor update. :type max_admm: int, default 1 :param rel_tol: Stop when the relative decrease of the fit error falls below this value. :type rel_tol: float, default 1e-10 :param abs_tol: Stop when fit_error / ||T|| falls below this value. :type abs_tol: float, default 1e-10 :param admm_tol: Tolerance of the inner ADMM loops. :type admm_tol: float, default 1e-8

:returns: * factors (list of np.ndarray) – Estimated [A, B, C]. * fit_error (np.ndarray) – Squared reconstruction error :math:\|\mathcal{T} - \hat{\mathcal{T}}\|^2 at initialization and after each iteration.

.. py:function:: init_stokes_factors(model, strategy=’random’, T=None) :module: pybbtd.solvers.stokes_admm

Initialize the Stokes factors.

:param model: Model defining the dimensions and ranks. :type model: Stokes :param strategy: "random" draws factors with :func:~pybbtd.stokes.generate_stokes_factors. "kmeans" clusters the pixels by their Stokes vectors (see :func:_kmeans_init). :type strategy: {“random”, “kmeans”}, default “random” :param T: Data tensor, required for "kmeans". :type T: np.ndarray, optional

:returns: A, B, C – Initial factor matrices; A and B are non-negative and each column of C is a valid Stokes vector. :rtype: np.ndarray

BBTD: ALS#

.. py:module:: pybbtd.solvers.bbtd_als

Alternating least squares (ALS) solver for the unconstrained BBTD model.

.. py:function:: fit_bbtd_als(model, T, init=’random’, max_iter=1000, abs_tol=1e-08, rel_tol=0.001) :module: pybbtd.solvers.bbtd_als

Fit an unconstrained BBTD with alternating least squares (ALS).

Each iteration solves a least-squares problem for A, B, C and D in turn, keeping the other factors fixed.

:param model: Model defining the dimensions and ranks. :type model: BBTD :param T: Fourth-order tensor of shape model.dims to decompose. :type T: np.ndarray :param init: Initialization strategy (see :func:init_bbtd_factors). :type init: {“random”, “svd”}, default “random” :param max_iter: Maximum number of iterations. :type max_iter: int, default 1000 :param abs_tol: Stop when the fit error falls below this value. :type abs_tol: float, default 1e-8 :param rel_tol: Stop when the relative decrease of the fit error falls below this value. :type rel_tol: float, default 1e-3

:returns: * factors (list of np.ndarray) – Estimated [A, B, C, D]. * fit_error (np.ndarray) – Relative reconstruction error :math:\|\mathcal{T} - \hat{\mathcal{T}}\| / \|\mathcal{T}\| at initialization and after each iteration.

.. py:function:: init_bbtd_factors(model, strategy=’random’, T=None) :module: pybbtd.solvers.bbtd_als

Initialize the BBTD factors.

:param model: Model defining the dimensions and ranks. :type model: BBTD :param strategy: "random" draws standard Gaussian entries. "svd" uses the leading singular vectors of each unfolding of T. :type strategy: {“random”, “svd”}, default “random” :param T: Data tensor, required for "svd". :type T: np.ndarray, optional

:returns: A, B, C, D – Initial factor matrices. :rtype: np.ndarray

BBTD: AO-ADMM for covariance images#

.. py:module:: pybbtd.solvers.bbtd_cov_admm

AO-ADMM solver for the BBTD model of covariance images.

The constrained model has non-negative spatial maps A_r @ B_r.T and conjugate-symmetric spectral factors D = C*, so the second block of each term is a covariance matrix C_r @ C_r^H.

.. py:function:: fit_bbtd_cov_admm(model, T, init=’random’, max_iter=1000, gamma=1.0, rho=1.0, max_admm=50, admm_tol=1e-08, rel_tol=1e-06, abs_tol=1e-12) :module: pybbtd.solvers.bbtd_cov_admm

Fit the covariance BBTD with AO-ADMM.

Enforces non-negative spatial maps A_r @ B_r.T and conjugate symmetry D = C*.

:param model: Model defining the dimensions and ranks. The data have shape (I, J, K, K). :type model: BBTD :param T: Tensor of shape model.dims whose pixels T[i, j] are K x K covariance matrices. :type T: np.ndarray :param init: Initialization strategy (see :func:init_bbtd_cov_factors). :type init: {“random”, “svd”, “kmeans”}, default “random” :param max_iter: Maximum number of outer iterations. :type max_iter: int, default 1000 :param gamma: Weight of the penalty tying A_r @ B_r.T to its non-negative part. :type gamma: float, default 1.0 :param rho: ADMM penalty parameter for the constraint D = C*. :type rho: float, default 1.0 :param max_admm: Maximum number of inner ADMM iterations for the C, D update. :type max_admm: int, default 50 :param admm_tol: Tolerance of the inner ADMM loop. :type admm_tol: float, default 1e-8 :param rel_tol: Stop when the relative change of the fit error falls below this value. :type rel_tol: float, default 1e-6 :param abs_tol: Stop when the fit error falls below this value. :type abs_tol: float, default 1e-12

:returns: * factors (list of np.ndarray) – Estimated [A, B, C, D], with D = C.conj(). * fit_error (np.ndarray) – Relative reconstruction error after each iteration.

.. py:function:: init_bbtd_cov_factors(model, strategy=’random’, T=None) :module: pybbtd.solvers.bbtd_cov_admm

Initialize the factors of the covariance BBTD.

A and B are non-negative and C is complex; D = C.conj() is implied.

:param model: Model defining the dimensions and ranks. :type model: BBTD :param strategy: "random" draws uniform A, B and complex Gaussian C. "svd" uses the leading singular vectors of the unfoldings of T (absolute values for A and B). "kmeans" clusters the pixels by their covariance matrices (see :func:_kmeans_init). :type strategy: {“random”, “svd”, “kmeans”}, default “random” :param T: Data tensor, required for "svd" and "kmeans". :type T: np.ndarray, optional

:returns: A, B, C – Initial factor matrices. :rtype: np.ndarray
