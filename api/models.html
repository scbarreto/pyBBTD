Models#

BTD#

.. py:module:: pybbtd.btd

Block term decomposition (BTD) of third-order tensors into rank-(L, L, 1) terms.

.. py:class:: BTD(dims, R, L, block_mode=’LL1’) :module: pybbtd.btd

Third-order tensor model made of R rank-(L, L, 1) block terms.

Each term is the outer product of a rank-L matrix and a vector. With the default "LL1" block mode, a tensor of shape (I, J, K) is written as

.. math::

   \mathcal{T} = \sum_{r=1}^{R} (\mathbf{A}_r \mathbf{B}_r^{\top})
   \circ \mathbf{c}_r,

with :math:\mathbf{A}_r of shape (I, L), :math:\mathbf{B}_r of shape (J, L) and :math:\mathbf{c}_r of length K. The modes "L1L" and "1LL" put the vector in the second or first mode instead.

:param dims: Shape (I, J, K) of the tensor. :type dims: tuple of int :param R: Number of block terms. :type R: int :param L: Rank of the matrix part of each term. A single integer is used for all R terms. :type L: int or sequence of int :param block_mode: Which mode holds the vector part of each term. :type block_mode: {“LL1”, “L1L”, “1LL”}, default “LL1”

.. attribute:: dims

  Shape of the tensor.

  :type: tuple of int

.. attribute:: rank

  Number of block terms R.

  :type: int

.. attribute:: L

  Rank of each term, shape ``(R,)``.

  :type: np.ndarray

.. attribute:: block_mode

  Block mode of the decomposition.

  :type: str

.. attribute:: factors

  Factor matrices ``[A, B, C]`` estimated by :meth:`fit`.

  :type: list of np.ndarray or None

.. attribute:: tensor

  Tensor rebuilt from ``factors`` by :meth:`fit`.

  :type: np.ndarray or None

.. attribute:: fit_error

  Fit error at each iteration of the last :meth:`fit`.

  :type: np.ndarray or None

.. py:method:: BTD.check_uniqueness() :module: pybbtd.btd

  Check a sufficient condition for the decomposition to be unique.

  A warning is issued when uniqueness cannot be guaranteed.

  :returns: ``True`` if uniqueness is guaranteed, ``False`` if it cannot be
            guaranteed, and ``None`` if the check is not available (it is
            only implemented when all terms share the same L).
  :rtype: bool or None

.. py:method:: BTD.fit(data, algorithm=’ALS’, **kwargs) :module: pybbtd.btd

  Estimate the factors that best explain ``data``.

  Updates :attr:`factors`, :attr:`tensor` and :attr:`fit_error`.

  :param data: Tensor of shape :attr:`dims` to decompose.
  :type data: np.ndarray
  :param algorithm: Fitting algorithm (see :func:`~pybbtd.solvers.btd_als.fit_btd_als`).
  :type algorithm: {"ALS"}, default "ALS"
  :param \*\*kwargs: Passed to the solver, e.g. ``init``, ``max_iter``, ``rel_tol``,
                     ``abs_tol``.

  :returns: The fitted model.
  :rtype: BTD

.. py:method:: BTD.get_constraint_matrix() :module: pybbtd.btd

  Return the matrix :math:`\Theta` that writes the BTD as a CP model.

  :math:`\Theta` repeats each column of the vector factor ``L[r]``
  times, so the BTD can be computed as a CP decomposition with
  ``sum(L)`` rank-one terms.

  :returns: Constraint matrix of shape ``(R, sum(L))``.
  :rtype: np.ndarray

.. py:function:: factors_to_tensor(A, B, C, theta, block_mode=’LL1’) :module: pybbtd.btd

Rebuild the full tensor from BTD factors.

:param A: Factor matrices. With block_mode="LL1", A and B have sum(L) columns and C has R columns; the other modes move the R-column factor accordingly. :type A: np.ndarray :param B: Factor matrices. With block_mode="LL1", A and B have sum(L) columns and C has R columns; the other modes move the R-column factor accordingly. :type B: np.ndarray :param C: Factor matrices. With block_mode="LL1", A and B have sum(L) columns and C has R columns; the other modes move the R-column factor accordingly. :type C: np.ndarray :param theta: Constraint matrix from :meth:BTD.get_constraint_matrix. :type theta: np.ndarray :param block_mode: Block mode of the decomposition. :type block_mode: {“LL1”, “L1L”, “1LL”}, default “LL1”

:returns: Tensor of shape (A.shape[0], B.shape[0], C.shape[0]). :rtype: np.ndarray

.. py:function:: spatial_maps(A, B, L) :module: pybbtd.btd

Return the matrix part :math:\mathbf{A}_r \mathbf{B}_r^{\top} of each term.

For imaging data these are the R spatial maps: images showing where each term is present.

:param A: Factor of shape (I, R * L), with the columns of term r in the r-th block of L columns. :type A: np.ndarray :param B: Factor of shape (J, R * L) with the same block structure. :type B: np.ndarray :param L: Number of columns per term. :type L: int

:returns: Array of shape (R, I, J). :rtype: np.ndarray

Cov-LL1#

.. py:module:: pybbtd.covll1

Cov-LL1 model: a BTD-LL1 for covariance imaging.

In covariance imaging, every pixel holds a K x K covariance matrix. The matrices are vectorized so the data form a tensor of shape (I, J, K**2), decomposed into R terms, each a non-negative spatial map times one vectorized covariance matrix.

.. py:class:: CovLL1(dims, R, L1, L2, block_mode=’LL1’) :module: pybbtd.covll1

Bases: :py:class:~pybbtd.btd.BTD

BTD-LL1 model whose vector factor holds vectorized covariance matrices.

Extends :class:~pybbtd.btd.BTD. Each column of the factor C, of length K**2, is a vectorized K x K covariance matrix.

:param dims: Shape (I, J, K**2) of the tensor. The last dimension must be a perfect square. :type dims: tuple of int :param R: Number of terms. :type R: int :param L1: Rank of the spatial maps. :type L1: int :param L2: Rank of the covariance matrices. Only used to generate synthetic data with :meth:generate_covll1_tensor; the fit does not constrain it. :type L2: int :param block_mode: Block mode of the decomposition. :type block_mode: {“LL1”, “L1L”, “1LL”}, default “LL1”

.. attribute:: L1, L2

  Ranks of the spatial maps and of the covariance matrices.

  :type: int

.. attribute:: factors

  Factor matrices ``[A, B, C]`` estimated by :meth:`fit`; ``A`` has
  shape ``(I, L1 * R)``, ``B`` has shape ``(J, L1 * R)`` and ``C`` has
  shape ``(K**2, R)``.

  :type: list of np.ndarray or None

.. attribute:: tensor

  Tensor rebuilt from ``factors`` by :meth:`fit`.

  :type: np.ndarray or None

.. attribute:: fit_error

  Fit error at each iteration of the last :meth:`fit`.

  :type: np.ndarray or None

.. py:method:: CovLL1.generate_covll1_tensor() :module: pybbtd.covll1

  Draw random Cov-LL1 factors and store them with their tensor.

  Updates :attr:`factors` and :attr:`tensor`.

  :returns: * **factors** (*list of np.ndarray*) -- ``[A, B, C]`` from :func:`generate_covll1_factors`.
            * **tensor** (*np.ndarray*) -- Tensor of shape :attr:`dims`.

.. py:method:: CovLL1.fit(data, algorithm=’ADMM’, **kwargs) :module: pybbtd.covll1

  Estimate the factors that best explain ``data``.

  Updates :attr:`factors`, :attr:`tensor` and :attr:`fit_error`.

  :param data: Tensor of shape ``(I, J, K**2)`` to decompose.
  :type data: np.ndarray
  :param algorithm: Fitting algorithm (see
                    :func:`~pybbtd.solvers.covll1_admm.fit_covll1_admm`).
  :type algorithm: {"ADMM"}, default "ADMM"
  :param \*\*kwargs: Passed to the solver, e.g. ``init``, ``max_iter``, ``rho``,
                     ``max_admm``, ``rel_tol``, ``abs_tol``, ``admm_tol``.

  :returns: The fitted model.
  :rtype: CovLL1

.. py:function:: generate_covll1_factors(dims, R, L1, L2) :module: pybbtd.covll1

Draw random factors for a Cov-LL1 model.

The spatial factors A, B are uniform on [0, 1). Each column of C is a vectorized K x K positive semidefinite Hermitian matrix of rank L2.

:param dims: Shape (I, J, K**2) of the tensor. :type dims: tuple of int :param R: Number of terms. :type R: int :param L1: Rank of the spatial maps. :type L1: int :param L2: Rank of the covariance matrices. :type L2: int

:returns: * A (np.ndarray) – Shape (I, L1 * R), non-negative. * B (np.ndarray) – Shape (J, L1 * R), non-negative. * C (np.ndarray) – Shape (K**2, R), one vectorized covariance matrix per column.

.. py:function:: validate_covariance_tensor(T) :module: pybbtd.covll1

Check that every pixel of a tensor holds a valid covariance matrix.

Each pixel T[i, j, :] is reshaped to K x K and tested with :func:is_valid_covariance. Warns with the percentage of invalid pixels, if any.

:param T: Tensor of shape (I, J, K**2). :type T: np.ndarray

:returns: True if all pixels are valid. :rtype: bool

.. py:function:: is_valid_covariance(Sigma, tol=1e-10) :module: pybbtd.covll1

Check that a matrix is a valid covariance matrix.

A valid covariance matrix is square, Hermitian and positive semidefinite.

:param Sigma: Matrix to test. :type Sigma: np.ndarray :param tol: Tolerance on the Hermitian symmetry and on negative eigenvalues. :type tol: float, default 1e-10

:rtype: bool

Stokes#

.. py:module:: pybbtd.stokes

Stokes model: a BTD-LL1 for polarization images.

Each pixel of a polarization image is described by a Stokes vector [S0, S1, S2, S3]: total intensity, and three numbers describing how the light is polarized. The tensor of shape (I, J, 4) is decomposed into R terms, each a non-negative spatial map times one Stokes vector.

.. py:class:: Stokes(spatial_dims, R, L) :module: pybbtd.stokes

Bases: :py:class:~pybbtd.btd.BTD

BTD-LL1 model for polarization images, with valid Stokes vectors.

Extends :class:~pybbtd.btd.BTD with the third mode fixed to size 4. Each column of the factor C is a physically valid Stokes vector (see :func:is_valid_stokes), and the spatial factors are non-negative.

:param spatial_dims: Image size (I, J). The tensor has shape (I, J, 4). :type spatial_dims: tuple of int :param R: Number of terms (polarization states). :type R: int :param L: Rank of the spatial map of each term. :type L: int or sequence of int

.. attribute:: factors

  Factor matrices ``[A, B, C]`` estimated by :meth:`fit`; ``C`` has
  shape ``(4, R)``.

  :type: list of np.ndarray or None

.. attribute:: tensor

  Tensor rebuilt from ``factors`` by :meth:`fit`.

  :type: np.ndarray or None

.. attribute:: fit_error

  Fit error at each iteration of the last :meth:`fit`.

  :type: np.ndarray or None

.. py:method:: Stokes.generate_stokes_tensor() :module: pybbtd.stokes

  Draw random Stokes factors and store them with their tensor.

  Updates :attr:`factors` and :attr:`tensor`.

  :returns: * **factors** (*list of np.ndarray*) -- ``[A, B, C]`` from :func:`generate_stokes_factors`.
            * **tensor** (*np.ndarray*) -- Tensor of shape ``(I, J, 4)``.

.. py:method:: Stokes.fit(data, algorithm=’ADMM’, **kwargs) :module: pybbtd.stokes

  Estimate the factors that best explain ``data``.

  Updates :attr:`factors`, :attr:`tensor` and :attr:`fit_error`.

  :param data: Tensor of shape ``(I, J, 4)`` to decompose.
  :type data: np.ndarray
  :param algorithm: Fitting algorithm (see
                    :func:`~pybbtd.solvers.stokes_admm.fit_stokes_admm`).
  :type algorithm: {"ADMM"}, default "ADMM"
  :param \*\*kwargs: Passed to the solver, e.g. ``init``, ``max_iter``, ``rho``,
                     ``max_admm``, ``rel_tol``, ``abs_tol``, ``admm_tol``.

  :returns: The fitted model.
  :rtype: Stokes

.. py:function:: generate_stokes_factors(dims, R, L) :module: pybbtd.stokes

Draw random factors for a Stokes model.

The spatial factors A, B are uniform on [0, 1). Each column of C is the Stokes vector of a random fully polarized state.

:param dims: Shape (I, J, 4) of the tensor. :type dims: tuple of int :param R: Number of terms. :type R: int :param L: Rank of the spatial maps; L[0] is used for every term. :type L: sequence of int

:returns: * A (np.ndarray) – Shape (I, L[0] * R), non-negative. * B (np.ndarray) – Shape (J, L[0] * R), non-negative. * C (np.ndarray) – Shape (4, R), one valid Stokes vector per column.

.. py:function:: validate_stokes_tensor(T) :module: pybbtd.stokes

Check that every pixel of a tensor holds a valid Stokes vector.

Warns with the percentage of invalid pixels, if any.

:param T: Tensor of shape (I, J, 4). :type T: np.ndarray

:returns: True if all pixels are valid. :rtype: bool

.. py:function:: is_valid_stokes(S) :module: pybbtd.stokes

Check that a Stokes vector is physically valid.

A valid Stokes vector has :math:S_0 \geq 0 and :math:S_0^2 \geq S_1^2 + S_2^2 + S_3^2 (the polarized part cannot carry more power than the total intensity). The comparison is rounded to 5 decimals.

:param S: Stokes vector [S0, S1, S2, S3]. :type S: np.ndarray

:rtype: bool

.. py:function:: stokes_to_coherency(S) :module: pybbtd.stokes

Convert a Stokes vector to its 2 x 2 coherency matrix.

:param S: Stokes vector [S0, S1, S2, S3]. :type S: np.ndarray

:returns: Complex Hermitian matrix of shape (2, 2). :rtype: np.ndarray

.. py:function:: coherency_to_stokes(coh) :module: pybbtd.stokes

Convert a 2 x 2 coherency matrix to its Stokes vector.

:param coh: Complex Hermitian matrix of shape (2, 2). :type coh: np.ndarray

:returns: Real Stokes vector [S0, S1, S2, S3]. :rtype: np.ndarray

.. py:function:: project_stokes(S) :module: pybbtd.stokes

Project a vector onto the set of valid Stokes vectors.

The vector is converted to a coherency matrix, projected onto the positive semidefinite matrices, and converted back.

:param S: Vector [S0, S1, S2, S3]. :type S: np.ndarray

:returns: The closest valid Stokes vector. :rtype: np.ndarray

BBTD#

.. py:module:: pybbtd.bbtd

Block-block term decomposition (BBTD) of fourth-order tensors.

.. py:class:: BBTD(dims, R, L1, L2) :module: pybbtd.bbtd

Fourth-order tensor model made of R rank-(L1, L1, L2, L2) terms.

A tensor of shape (I, J, K, M) is written as

.. math::

   \mathcal{T} = \sum_{r=1}^{R} (\mathbf{A}_r \mathbf{B}_r^{\top})
   \circ (\mathbf{C}_r \mathbf{D}_r^{\top}),

where :math:\mathbf{A}_r \mathbf{B}_r^{\top} is a rank-L1 matrix of shape (I, J) (for imaging data, a spatial map) and :math:\mathbf{C}_r \mathbf{D}_r^{\top} is a rank-L2 matrix of shape (K, M). For covariance imaging, K = M and :math:\mathbf{D}_r = \mathbf{C}_r^*, so the second block is a covariance matrix :math:\mathbf{C}_r \mathbf{C}_r^{H}.

:param dims: Shape (I, J, K, M) of the tensor. :type dims: tuple of int :param R: Number of terms. :type R: int :param L1: Rank of the first block (shared by A and B). :type L1: int :param L2: Rank of the second block (shared by C and D). :type L2: int

.. attribute:: dims

  Shape of the tensor.

  :type: tuple of int

.. attribute:: rank

  Number of terms R.

  :type: int

.. attribute:: L1, L2

  Block ranks.

  :type: int

.. attribute:: factors

  Factor matrices ``[A, B, C, D]`` estimated by :meth:`fit`.

  :type: list of np.ndarray or None

.. attribute:: tensor

  Tensor rebuilt from ``factors`` by :meth:`fit`.

  :type: np.ndarray or None

.. attribute:: fit_error

  Fit error at each iteration of the last :meth:`fit`.

  :type: np.ndarray or None

.. py:method:: BBTD.check_uniqueness() :module: pybbtd.bbtd

  Check a sufficient condition for the decomposition to be unique.

  A warning is issued when uniqueness cannot be guaranteed.

  :returns: ``True`` if uniqueness is guaranteed.
  :rtype: bool

.. py:method:: BBTD.get_constraint_matrices() :module: pybbtd.bbtd

  Return the matrices :math:`\Phi` and :math:`\Psi` that write the BBTD as a CP model.

  With them, the BBTD equals a CP decomposition with ``L1 * L2 * R``
  rank-one terms and factors ``A @ phi``, ``B @ phi``, ``C @ psi`` and
  ``D @ psi``.

  :returns: * **phi** (*np.ndarray*) -- Shape ``(L1 * R, L1 * L2 * R)``.
            * **psi** (*np.ndarray*) -- Shape ``(L2 * R, L1 * L2 * R)``.

.. py:method:: BBTD.fit(data, algorithm=’ALS’, **kwargs) :module: pybbtd.bbtd

  Estimate the factors that best explain ``data``.

  Updates :attr:`factors`, :attr:`tensor` and :attr:`fit_error`.

  :param data: Tensor of shape :attr:`dims` to decompose.
  :type data: np.ndarray
  :param algorithm: ``"ALS"`` fits an unconstrained BBTD
                    (:func:`~pybbtd.solvers.bbtd_als.fit_bbtd_als`). ``"ADMM"`` fits
                    the covariance model, with non-negative spatial maps and
                    ``D = C*`` (:func:`~pybbtd.solvers.bbtd_cov_admm.fit_bbtd_cov_admm`).
  :type algorithm: {"ALS", "ADMM"}, default "ALS"
  :param \*\*kwargs: Passed to the solver, e.g. ``init``, ``max_iter``, ``rel_tol``,
                     ``abs_tol``.

  :returns: The fitted model.
  :rtype: BBTD

.. py:function:: factors_to_tensor(A, B, C, D, phi, psi) :module: pybbtd.bbtd

Rebuild the full fourth-order tensor from BBTD factors.

:param A: Factor of shape (I, L1 * R). :type A: np.ndarray :param B: Factor of shape (J, L1 * R). :type B: np.ndarray :param C: Factor of shape (K, L2 * R). :type C: np.ndarray :param D: Factor of shape (M, L2 * R). :type D: np.ndarray :param phi: Constraint matrices from :meth:BBTD.get_constraint_matrices. :type phi: np.ndarray :param psi: Constraint matrices from :meth:BBTD.get_constraint_matrices. :type psi: np.ndarray

:returns: Tensor of shape (I, J, K, M). :rtype: np.ndarray
